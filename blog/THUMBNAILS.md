# Thumbnail source note

The blog package uses **local topic-specific illustrated thumbnails** rather than hotlinking third-party images. This keeps the GitHub Pages site fast and prevents broken external image URLs.

If you want photographic thumbnails later, Pexels is a suitable source: its current licensing help states that Pexels photos/videos can be used on commercial websites and blogs, subject to its restrictions. See:
https://help.pexels.com/hc/en-us/articles/360042295214-Can-I-use-the-photos-and-videos-for-a-commercial-project

Useful searches:
- https://www.pexels.com/search/graphic%20design/
- https://www.pexels.com/search/graphic%20designer/
- https://www.pexels.com/search/graphic%20design%20photoshop/
- https://www.pexels.com/search/illustrator/
